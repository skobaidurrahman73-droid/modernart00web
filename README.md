# Modern Art & Press

Complete starter package containing the Customer, Designer and Admin HTML pages,
CSS and JavaScript files.

## Structure

- index.html — Customer entry/login
- register.html — Customer registration
- customer.html — Customer dashboard
- designers.html — Designer selection
- chat.html — Chat UI
- files.html — Customer files
- designer-login.html — Designer login
- designer.html — Designer dashboard
- admin-login.html — Admin login
- admin.html — Admin dashboard
- css/style.css — Shared styling
- js/config.js — Easy-to-edit shop/designer settings
- js/app.js — Demo application logic
- js/firebase-config.js — Firebase project configuration

## Important
This is a starter/demo build. Real production authentication, Firestore
permissions, Storage security, QR receipt validation, chat retention and
server-side file expiry still need to be implemented before real customer data
or design files are used.
